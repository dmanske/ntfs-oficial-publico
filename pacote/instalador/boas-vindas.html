NTFS Oficial

Este instalador coloca no seu Mac o driver para ler e gravar discos formatados em NTFS (Windows), com o aplicativo NTFS Oficial na barra de menus.

Antes de instalar: o driver usa uma extensão de kernel. Para ela funcionar, a proteção do sistema do Mac precisa estar reduzida (veja o passo a passo no README do projeto).

No primeiro uso: o macOS vai pedir para permitir a extensão. Abra Ajustes do Sistema → Privacidade e Segurança, permita a extensão e reinicie o Mac.

Este instalador não é assinado pela Apple; é normal o macOS avisar disso.
